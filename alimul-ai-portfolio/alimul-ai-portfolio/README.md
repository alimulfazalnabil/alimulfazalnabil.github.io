# Alimul Fazal Nabil — AI Solutions Engineer Portfolio

A production-oriented personal portfolio for the German/EU AI market.

## Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Lucide React
- Docker

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm start
```

## Customize
1. Add the final CV PDF as `public/Alimul-Fazal-Nabil-AI-Solutions-Engineer-CV.pdf`.
2. Replace project descriptions with verified GitHub repositories and live demos.
3. Add a professional headshot if desired.
4. Update contact/social URLs if required.
