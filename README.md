# Editorial Minimal Portfolio — Alimul Fazal Nabil

A standalone, responsive static portfolio with editorial typography, a light/dark theme toggle, and no build step. Designed and deployed directly through GitHub Pages.

## Overview
This site represents the professional portfolio of **Alimul Fazal Nabil** — AI Solutions Engineer specializing in Generative AI, machine learning, RAG, AI agents, MLOps, and cloud systems.

## Files
- `index.html` — page structure and content
- `assets/css/styles.css` — theme tokens, layout, typography, responsive styles
- `assets/js/main.js` — theme toggle, mobile navigation, dynamic year
- `assets/images/` — verified local assets including profile image (`profile.jpg`)
- `.nojekyll` — ensures static asset loading on GitHub Pages

## Preview Locally
Open `index.html` in any browser, or run a local server:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Features
- **Editorial Typography**: Styled with DM Sans, DM Mono, Manrope, and Georgia serif italics.
- **Light & Dark Themes**: Preserved user preference in `localStorage` with system theme detection.
- **Interactive SVG & CSS Diagram Art**: Visual architectural schematics for RAG pipelines, intelligent transport, computer vision lanes, pulse health monitoring, and cloud delivery.
- **Zero Build Step**: Pure HTML5, CSS3, and modern vanilla JavaScript.
